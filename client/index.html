SSH & Download instructions

Direct SSH to the container is not provided. Use the web terminal above for interactive access. To download files from your workspace to your local machine, use the downloadfile helper inside the web shell, or use the HTTP endpoint shown below.

Using the in-shell helper

# In the web terminal run:
downloadfile path/to/file -o myfile.txt
# This copies the file to your workspace ~/Downloads and signals the browser to download it.

Download via curl (from your local machine or SSH session)

curl -o ~/Downloads/FILE_NAME "https://YOUR_SERVICE/workspaces/WORKSPACE_ID/download?file=REL_PATH"

Replace WORKSPACE_ID and REL_PATH with the values shown in the terminal when your workspace starts (you can also copy them from the web terminal message).

This session runs inside an isolated workspace folder; it will not use your project files.
